# SatQuery Dataset & Fine-Tuning Pipeline

This directory contains the **dataset construction** and **fine-tuning** pipelines for SatQuery AI.

> **Status:** Pipeline scripts are complete and tested. **No checkpoints or datasets are committed** — they are large (multi-GB), publicly hosted, and generated at runtime.

---

```
dataset_pipeline/
```

## Quickstart: Dataset Construction

### 1. EarthDial India Dataset (VLM fine-tuning)

```bash
cd dataset_pipeline/earthdial_india

# Phase 1: AOI sampling & metadata extraction
python phase1_generate.py --config config.yaml

# Populate M0 catalog from Planetary Computer (requires network)
python populate_assam_scenes.py --aois config/aois_tier1.yaml

# Generate seed pool for fine-tuning
python create_seed_pool.py --output data/seeds/

# Rebalance for class balance
python rebalance_seed_pool.py --input data/seeds/ --output data/seeds_balanced/
```

### 2. LLM Parser Dataset (Phi-4-mini)

See `PHI4_PARSER_DATASET_BUILD_PLAN.md` for the complete methodology.

```bash
# Generate synthetic + real query pairs
python dataset_pipeline/training/prepare_data.py --task parser
```

## Quickstart: Fine-Tuning

> **Requires GPU** (tested on RTX 3090 / A100). CPU-only will not work.

```bash
cd dataset_pipeline/training

# Install GPU dependencies
pip install torch bitsandbytes accelerate peft

# Fine-tune EarthDial (VLM) with LoRA
python train_lora.py \
  --model mbzuai-oryx/GeoChat \
  --data_dir ../earthdial_india/data/seeds_balanced/ \
  --output_dir ./models/geochat_lora \
  --lora_r 16 --lora_alpha 32 \
  --batch_size 4 --epochs 3

# Fine-tune Phi-4-mini (Parser) with LoRA
python train_lora.py \
  --model microsoft/Phi-4-mini-instruct \
  --data_dir data/parser_seeds/ \
  --output_dir ./models/phi4_lora \
  --lora_r 8 --lora_alpha 16
```

## Outputs (Not in Repo)

After training, upload checkpoints to **Hugging Face Hub**:

```bash
# Example: push LoRA adapter
huggingface-cli upload your-org/satquery-geochat-lora ./models/geochat_lora/
```

Then reference in `config.yaml`:
```yaml
vlm:
  lora_adapter_path: "your-org/satquery-geochat-lora"  # HF Hub path
```

## Why Not Commit Data/Checkpoints?

| Reason | Detail |
|--------|--------|
| **Size** | BigEarthNet = 500GB, LoRA = 200MB+ — GitHub rejects >100MB without LFS |
| **Provenance** | Datasets already hosted canonically (BigEarth.net, HF Hub) |
| **Reproducibility** | Scripts generate exact same data; committing adds no value |
| **License** | Some datasets have redistribution restrictions |
